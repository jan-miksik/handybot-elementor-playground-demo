# HandyBot Elementor Playground demo

Veřejný demonstrační projekt pro ověření editace HandyBot homepage ve
WordPressu a Elementoru.

## Spustit demo

[Otevřít HandyBot demo ve WordPress Playgroundu](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fjan-miksik%2Fhandybot-elementor-playground-demo%2Fmain%2Fblueprint.json)

Playground vytvoří novou izolovanou kopii WordPressu přímo v prohlížeči,
nainstaluje Elementor a potřebná témata a automaticky přihlásí uživatele.

Každé otevření odkazu vytváří vlastní kopii. Změny lze uložit v prohlížeči
nebo exportovat jako ZIP, ale nejsou automaticky sdílené s ostatními testery.

## Obsah repozitáře

- `blueprint.json` – automatická instalace dema;
- `handybot-child/` – child theme a grafické podklady;
- `handybot-demo-setup/` – vytvoření editovatelné Elementor homepage.

Toto je demonstrační projekt, nikoli produkční web HandyBot.
